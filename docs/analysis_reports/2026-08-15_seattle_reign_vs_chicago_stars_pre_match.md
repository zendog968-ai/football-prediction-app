# 西雅圖女王女足 vs 芝加哥之星女足：賽前研究分析

## 二、基礎機率估計

本節並非Aurelia的已校準16範圍XGBoost輸出，而是為了本場女子聯賽資料覆蓋不足所做的**透明、未校準Poisson基礎估計**。計算只使用上表的賽前進失球總數：

\[
\lambda_{\text{西雅圖}} = \frac{(22/17) + (33/18)}{2} = 1.564
\]

\[
\lambda_{\text{芝加哥}} = \frac{(9/18) + (23/17)}{2} = 0.926
\]

| 研究項目 | 基礎估計 | 讀法 |
|---|---:|---|
| 西雅圖勝 | **52.2%** | 主隊在進攻產量與對手失球率的合成指標佔優。 |
| 和局 | **25.4%** | 芝加哥近期0–0、以及教練更替後可能收窄陣型，使和局不能忽略。 |
| 芝加哥勝 | **22.3%** | 需要其低產量進攻有效轉化，或透過定位球提高單場效率。 |
| 小於2.5球 | **54.6%** | 與西雅圖近期多場入球的趨勢並不完全一致，反映本模型對芝加哥低得分率的權重。 |
| 大於2.5球 | **45.4%** | 若芝加哥的定位球成功，或比賽早段出現入球，這一側的機率會上升。 |

最常見的獨立比分格局依序為**1–0（13.0%）**、**1–1（12.0%）**、**2–0（10.1%）**、**2–1（9.4%）**與**0–0（8.3%）**。這些是單一比分格的機率，而不是結果保證。

> **模型限制：**此Poisson估計未使用球員層級xG、即時正選、賽程疲勞、紅牌、天氣、盤口或經校準的女子NWSL專屬歷史模型。因此只能視作比賽結構的基礎量化，不宜與平台已校準聯賽機率混為一談。

## 三、戰術勝負手

西雅圖的主攻方向應是用寬度製造禁區內二次進攻。獨立賽前資料顯示，西雅圖每場成功傳中為聯賽第三多的5.1次，而芝加哥的2.2次為聯賽最低；若西雅圖能在邊路持續形成高質量傳送，再由第二線搶點，芝加哥後防與門將Katie Atkinson的高工作量會被放大。[3] 不過，西雅圖要避免只以大量傳中取代禁區前的結構性滲透，否則容易落入芝加哥密集防守與清道夫式解圍的節奏。

芝加哥最清晰的反制路徑是**定位球與長傳後的第二落點**。其賽季九個入球中有六個來自定位球；同一份資料指出西雅圖已失七個定位球入球，屬聯賽較高數字。[3] 因此，雖然基本機率偏向主隊，西雅圖在角球、自由球與快速重開時的防守紀律，是足以改變比賽的單一高槓桿因素。

人事上，芝加哥在賽前更換主帥與技術團隊，增加陣型、壓迫高度及換人策略的不確定性。[4] 此外，獨立賽前報導列出芝加哥的Huitema、Grosso與Kuikka等傷停，並指出Swanson的可用性待確認；西雅圖方面則有Fishlock與Meza等人列於缺陣名單。[3] 正選公布後，應優先重新檢查這些資訊，而不要把賽前傷停名單當成最終事實。

## 四、情境判讀與數據傾向

| 比賽情境 | 可能走勢 | 研究重點 |
|---|---|---|
| 西雅圖先入球 | 芝加哥需提高壓迫與前推人數，西雅圖邊路反擊及第二球空間增加。 | 主隊最有利於把比賽導向2–0或2–1的情境。 |
| 0–0維持至半場 | 芝加哥低位防守策略奏效，和局與小比分的重要性上升。 | 西雅圖須提升禁區前滲透，並避免死球失誤。 |
| 芝加哥取得定位球優勢 | 其低產量運動戰可被死球抵消。 | 西雅圖應縮短禁區內盯人與第二點反應時間。 |

**數據傾向（研究）：西雅圖不敗一側，主勝為三分類中最高機率。** 優勢來自主場、較佳的賽季進攻輸出、對手作客紀錄以及芝加哥的高失球率；但這不是低風險結論。芝加哥新教練團的首戰效應、定位球威脅與兩隊過去在Lumen Field的3–3比賽，都使「西雅圖小勝或被逼和」比單向大勝更符合目前證據。[2] [3]
