# Aurelia Football 研究輸出範本：Lean與風險界限

## 適用條件

只有當聯賽、兩隊及資料截點均通過模型範圍驗證，且三分類機率為有限數、落在0至1之間並加總為1時，才輸出「數據傾向（Lean）」。Out-of-Scope、資料庫無隊伍或未校準的跨範圍對戰維持拒絕輸出機率；不能用Lean取代資料驗證。

## 固定輸出順序

| 區塊 | 必須內容 | 輸出規則 |
|---|---|---|
| 1. 校準機率 | 主勝／和局／客勝及資料截點 | 保留完整三分類分佈，不把Lean冒充為新的機率模型。 |
| 2. 數據傾向（Lean） | 最高機率結果、對應球隊或和局、最高機率值 | 在範圍內結果必須輸出；它是「最高校準機率方向」，不是投注指令。 |
| 3. 證據理由 | Elo方向、近五場方向、主客場或其他可用賽前特徵 | 僅列出真實回放特徵；缺失xG保持缺失。 |
| 4. 風險分級 | 較低／中等／高風險與具體限制 | DC不足、低樣本或首二機率距離小時升級風險，不移除Lean。 |
| 5. 入球及價格 | 只有DC可用時才輸出隊伍專屬入球結論；公平價採`1 ÷ 機率` | 無DC時只能報告聯盟層級歷史背景，不能偽裝為本場O/U或BTTS機率。 |
| 6. 研究護欄 | 歷史資料截點、資料限制與非資金建議聲明 | 不提供注碼、下單步驟或結果保證。 |

## 風險分級規則

`高風險`適用於Dixon–Coles不可用、可用歷史少於300場，或最高與次高三分類機率差距少於8個百分點。`中等風險`適用於差距少於15個百分點或樣本少於1,000場；其餘才可標示為`較低風險`。分級描述模型證據限制，並不表示任何結果安全或應採取行動。

> **範例用語：**「數據傾向：主勝傾向（46.2%）；高風險。最高校準機率、Elo及近期勝率均偏向主隊，但Dixon–Coles資料不足，不能延伸為隊伍專屬入球結論。」
