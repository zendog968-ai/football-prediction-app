## 二、模型與特徵升級

升級管線保存加權近5場進失球、主隊主場與客隊客場拆分、休養天數、動態Elo、xG可用性、Dixon–Coles `rho`，以及可用時的去水1X2隱含機率。新建的`model_feature_snapshots`表會持久化每次同步所使用的賽前特徵，方便日後追溯。

低比分機率以Dixon–Coles Tau校正處理0–0、1–0、0–1與1–1；若該fixture存在完整且驗證的HDA盤口，則把去水後市場機率與模型1X2機率以50/50融合。沒有盤口時，系統只保留模型機率與缺失標記。

## 五、部署狀態與限制

即時研究與Python同步已具備Dixon–Coles低比分校正、完整HDA去水融合、雙重機率與研究分層。新增特徵快取表已由Supabase SQL Editor建立；在賽程資料源恢復後，2026年8月17日同步已實際寫入fixture `1492335` 的首筆特徵快照及融合預測。該列記錄了主客Elo、休養日、加權攻防、`rho=-0.12`、去水後1X2隱含機率與`xg_source_available=false`。

進一步改善應優先取得合規的歷史xG與帶時間戳記的賽前封盤1X2賠率，然後以完全相同的時間序列規則重新回測融合權重，避免以缺少歷史覆蓋的特徵宣稱效果提升。
