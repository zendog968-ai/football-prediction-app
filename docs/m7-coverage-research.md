# 7M 聯賽覆蓋對標基準

最後核實：2026-08-15（香港時間）

7M比分公開賽事頁顯示其「所有」篩選，以及多個跨洲與次級／青年／女子／盃賽類別；頁面可見例子包括英超、意甲、西甲、德甲、法甲、蘇超、英格蘭非聯賽、阿曼聯、澳洲女子聯賽、伊拉克聯、印度甲、利比亞甲、法國女子甲及多個盃賽。此證實對標目標不是只涵蓋少數熱門聯賽。

然而，7M公開頁面並未提供可機器讀取、版本化的「完整App篩選清單」或官方授權的批次同步端點。因此本專案不會聲稱逐項鏡像私有App清單；改採API-Football授權聯賽目錄作為可稽核的同步母集，並以分層策略控制每日API用量與資料品質。

## 公開來源

1. [7M比分賽事列表](https://www.7m.hk/scores/)：即時頁面可見「所有」篩選與跨洲聯賽／盃賽清單。
2. [7M App Store描述](https://apps.apple.com/us/app/7m%E5%8D%B3%E6%97%B6%E6%AF%94%E5%88%86-%E8%B6%B3%E7%90%83%E6%8E%A2%E7%B4%A2%E9%A2%84%E6%B5%8B%E5%88%86%E6%9E%90%E4%BD%93%E8%82%B2%E7%BD%91/id487115059)：公開頁面在本次核實時未能載入完整產品描述，故不作完整聯賽清單的權威依據。

## 授權數據源容量觀測

2026-08-15向API-Football授權端點取得的`leagues?current=true`目錄共有1,232個聯賽／盃賽條目，涵蓋170個國家或地區，其中776項標記為League、456項標記為Cup。相同日期的`fixtures?date=2026-08-15`全量回應共有1,217場賽事、293個聯賽、85個國家或地區；這個日期實例包含阿根廷各級聯賽、奧地利甲乙及地區聯賽、澳洲州級NPL等非熱門賽事。

此數據源帳戶為Pro方案，核實時每日上限為7,500個請求，已使用242個。全量日賽程可用單一端點讀取；但逐場賠率、歷史與研究需要額外請求與大量儲存。因此實作必須分離「全量賽程及隊伍識別同步」與「可驗證賠率／歷史研究同步」，並保留每次工作的可稽核計數，避免把未抓到的賠率或歷史資料誤宣稱為已覆蓋。
