# 名古屋鯨魚對鳥取飛翔：賽前研究來源摘要

名古屋鯨魚對鳥取飛翔是2026年8月26日日本天皇盃第106回第2回合，於豐田球場18:30 JST開賽，即17:30 HKT。名古屋官方頁面與日本足協賽程同樣確認對手、日期、輪次和場地。

日本足協的比賽頁把名古屋標註為J1隊伍，鳥取為鳥取縣代表，並列示兩隊登錄球員與教練。J聯盟官方賽前看點指出，鳥取首回合對熊本鏖戰至加時及互射十二碼才晉級。鳥取官方賽程列示其最近三場J3戰績為主場1–1 FC大阪、作客0–4愛媛、主場2–1福島；天皇盃首回合對熊本為2–2、互射十二碼6–5取勝。
