# 大阪櫻花對FC岐阜：賽前研究來源摘要

大阪櫻花對FC岐阜是2026年8月26日日本天皇盃第106回第2回合，於YANMAR HANASAKA STADIUM 18:30 JST開賽，即17:30 HKT。日本足協官方頁確認輪次、場地及兩隊登錄名單。

大阪櫻花官方賽前預覽表示，球隊三日前在J1以1–0擊敗清水；其後兩日即要作客神戶，賽程密集使本場存在一定先發輪換可能。該預覽同時確認FC岐阜暫居J3榜首；FC岐阜近三場正式聯賽為作客3–0滋賀、主場7–0高知、作客0–0鹿兒島。官方預覽明確指出岐阜的攻擊型風格與武颯在天皇盃首回合的兩個入球，並提醒這並非低強度對手。
