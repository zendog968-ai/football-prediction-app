# Aurelia 研究模式營運防護

更新日期：2026-10-19（HKT）

## 本次工作範圍

以 GitHub `zendog968-ai/football-prediction-app` 的 `73ed19d098fb017932e2ac306c65eeae80f0f34b` 為基線，落實研究模式防護。這是程式與輸出政策修復，**不是新校準器訓練，也不是前瞻命中率認證**。

實際遠端版本已包含 `poisson-v4-shrink10-research`、主客隊各至少5場／聯賽至少20場有效樣本、10場先驗收縮及賽前時間截點。先前 Sandbox 的舊檔案不代表 GitHub 最新 main；本次從最新 main 建立獨立工作區，不會把舊 v2/v3 覆蓋到 v4。

## 固定營運政策

| 項目 | 行為 |
|---|---|
| 機率 | 保留有效研究機率；不改 Poisson 概率公式 |
| 資料基礎 | 顯示每隊與聯賽實際有效樣本；缺失顯示未提供 |
| 校準狀態 | `uncalibrated`；資料樣本多不代表已校準 |
| 高信心篩選 | 停用；每日候選按樣本品質，同品質按開賽時間排序 |
| 資料不足 | 缺失或不足5/5/20，不以極高機率或舊資料補滿 |
| 星級 | 不把舊 `confidence` 欄位作命中率信心；對外快取值設0 |
| 投注訊號 | 不對外顯示資料庫舊版自由文字推薦 |
| EV | 研究模式停用數值與正EV標記；不把機率當公平賠率 |
| 真實盤口 | 仍只顯示已驗證市場快照；無市場資料不以模型製造水位 |
| 本地化 | 保留已有中文隊名及HKT開賽時間 |

Telegram 研究卡與服務標頭明示：

> 未校準研究；百分比不是保證命中率。高信心篩選停用；投注建議與EV停用。

有效研究可以在沒有即時讓球盤時仍顯示主客和、雙重機率、大小球及波膽；缺少盤口會明確提示，而不是冒充市場報價。

## 前瞻校準不能由本次修改直接完成

現有 `scripts/evaluate_poisson_quality.py` 明確把歷史回放標記為 paired chronological historical regression，而非 untouched prospective OOT。這類回放及舊 XGBoost Dashboard 績效，不能直接證明目前 Poisson v4 推播已前瞻校準。

下一階段必須固定同一模型版本，記錄賽前預測時間、資料實際可用時間、原始主和客機率、樣本、fixture ID與完場結果，並使用較早訓練／校準窗口及未碰過的較晚測試窗口。校準方法及發布門檻必須事先確定，再比較校準前後 Log-Loss、Brier、RPS、可靠度曲線及分聯賽結果。不應先看到測試結果才反覆改校準器。

主和客校準不能自動等同大小球與波膽已校準；若只完成1X2驗證，其他市場仍需分開標示研究值。任何校準成功也不是單場結果保證。

## 舊資料表的相容處理

`recommendation` 既有長度只有50字元。只保留樣本、丟掉預期入球，會令快取失去生成大小球及波膽的依據。本次使用完整 JSON `q4` 五元組，順序為：主隊預期入球、客隊預期入球、主隊樣本、客隊樣本、聯賽樣本；`q4` 只能代表固定 v4 未校準研究，不是校準成功碼。保留 `[AURELIA_META]` 標記及換行，長度仍不超過50字元；不截斷JSON，也不用改資料表。

快取同時相容舊的 `s=Q4` 加 `h/a` 與長樣本欄位，以及 `n` 樣本陣列。欠缺可验证樣本或目標版本時不把舊資料重新當作有效預測。
